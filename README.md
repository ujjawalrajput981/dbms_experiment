## 🎯 Learning Objectives
Through these laboratory experiments, I strengthened my understanding of:
- Entity-Relationship (ER) modeling and relational schema design.
- SQL commands, constraints, joins, and subqueries.
- Functional dependencies and step-by-step normalization (1NF, 2NF, 3NF, and BCNF).
- Transaction management and ACID properties using `COMMIT`, `ROLLBACK`, and `SAVEPOINT`.
- Query performance analysis using `EXPLAIN` and `EXPLAIN ANALYZE`.
- Indexing strategies (single-column, composite, leftmost-prefix rule) and query rewriting.
- Version control and project documentation using Git and GitHub.

## 🚀 Getting Started
Clone the repository:
```bash
git clone https://github.com/ujjawalrajput981/dbms_experiment.git
```

Navigate to the repository:
```bash
cd dbms_experiment
```

Open any experiment folder and execute its `.sql` file using MySQL Workbench or the MySQL 8.0+ CLI (required for recursive CTEs and `EXPLAIN ANALYZE` in Experiments 9 and 10). Refer to the included diagrams and screenshots where available.
